# ITASO

Web en React y TypeScript basada en el prototipo de Figma.

Consulta [INTEGRACION.md](./INTEGRACION.md) para ejecutar el proyecto, integrar los juegos, configurar las cuentas y conocer las funciones pendientes.

Los juegos están representados por botones. El selector de avatar funciona con los seis SVG originales y muestra la opción seleccionada en gris.
